# Contract: пользовательская команда загрузки (UI)

**Feature**: [spec.md](../spec.md) | **Plan**: [plan.md](../plan.md)

## Регистрация в Eclipse

- **Command id**: `io.github.fastsync.edt.commands.uploadSources`
- Точка расширения: `org.eclipse.ui.commands`; обработчик — `io.github.fastsync.edt.upload.UploadSourcesHandler` (`org.eclipse.ui.handlers`).
- Меню: контекстное меню `Project Explorer` (`popup:org.eclipse.ui.navigator.ProjectExplorer#Popup`), `visibleWhen`: выделен ровно один `org.eclipse.core.resources.IProject`.
- Команда **не** перехватывает и не отменяет штатную загрузку EDT; обработчик не регистрируется на существующие команды/сочетания клавиш.
- Строки меню/диалогов — из `messages.properties` (базовый английский) и `messages_ru.properties` (русский); ни одна строка не зашита в код.

## Сценарий

1. Пользователь выбирает проект и выполняет команду.
2. Выполняется preflight (см. [spec.md](../spec.md) FR-003…FR-005). При провале — диалог с причиной, база не меняется, никаких фоновых задач не запускается.
3. Показывается диалог выбора режима:
   - `Полная загрузка` — импорт всей конфигурации;
   - `Частичная загрузка` — только несинхронизированные изменения;
   - в диалоге отображаются проект, ИБ (путь), версия платформы и путь `ibcmd`.
   - Отмена диалога = отмена операции (ИБ не тронута).
4. Запускается `Job` (`setUser(true)`): прогресс в Progress View, кнопка Cancel. Операция не выполняется в UI-потоке.
5. Вывод `ibcmd` (команды, stdout/stderr, код возврата) — в консоль `FastSync ibcmd` (Console View). Пароли маскируются.
6. Итог — `MessageDialog` (успех/ошибка/предупреждение/отмена) и запись в Error Log. Отчёт честно перечисляет, что импортировано, что применено и что осталось.

## Ошибки и подтверждения

| Ситуация | Поведение |
|----------|-----------|
| Нет приложения / не ИБ / не файловая / нет версии / нет установки / нет `ibcmd` | отказ до изменения ИБ, диалог с причиной |
| ИБ заблокирована, нет доступа, каталог отсутствует | отказ/ошибка с причиной; без попыток «исправить» базу |
| Частичная загрузка, изменений нет | сообщение «загружать нечего», ИБ не тронута |
| Удаление/переименование в частичных изменениях | фактически выполняется полная загрузка, пользователю показывается причина |
| `config apply` требует `--force` | диалог подтверждения; при согласии — повтор `config apply --force` один раз; при отказе — отчёт «импортировано, но не применено», синхронизация не обновляется |
| Сеансы пользователей мешают apply | `--session-terminate=force` не передаётся, сеансы не завершаются; отчёт о блокировке |
| Не удалось безопасно закрыть/восстановить сеанс агента | отказ до изменения ИБ / явная ошибка восстановления; процесс агента не завершается |
| Отмена | остановка на безопасной границе, восстановление сеанса, отчёт о состоянии ИБ |

## Запрещено

- Молча выбирать режим, молча использовать `--force`, передавать `--session-terminate=force`, завершать сеансы, создавать ИБ, логировать секреты, изменять исходники проекта, выполнять операцию в UI-потоке.
